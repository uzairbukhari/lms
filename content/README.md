# Seed content

- `lessons/` is generated by `node scripts/build-lessons.mjs` from the authoring files in `scripts/lessons/` (helpers and guideline checks in `scripts/lesson-kit.mjs`). Week 1 (`diag-*`) and week 2 (`w2-*`), 10 lessons each. Edit the `.mjs` files, not the JSON.
- `VIDEO_SLOTS.md` lists the concept in each lesson that is waiting for an approved video.
- `lessons/` holds lesson files in the app's lesson format (schema 1.0). Validated by `worker/src/content.test.ts`.
- `seed/week1.sql` and `seed/week2.sql` are generated by `node scripts/build-seed.mjs`. It creates Class 1 and Class 4, their four semesters
  (Mon 2 Nov 2026, 12 teaching weeks + exam week, then a one week break), one published course per subject per class,
  the eight Week 1 diagnostic lessons with their quizzes, and the course assignments (due Sunday 8 Nov 2026).
  Every statement is idempotent. It contains no student names or passwords: student accounts are created in the parent area.

Apply it with `cd worker && npx wrangler d1 execute lms-db --remote --file ../content/seed/week1.sql`.
(Already applied to the live database on 2 Nov 2026.)

Reading the diagnostic: every quiz question has a `skill_tag`, so the Reports page shows strengths and gaps by skill.
Use each child's first attempt as the baseline.

What a lesson can contain (and what is planned) is kept in `docs/LESSON_CAPABILITIES.md`.
