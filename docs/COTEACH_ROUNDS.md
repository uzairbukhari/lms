# Coteach diagram rounds (paste into claude.ai)

How to use: open claude.ai, check the Coteach connector is on, paste ONE round as a message, tick all the diagrams in the preview, click Download, then move the PNGs into `C:\GitHub\lms\content\media\files\` and tell Claude Code "round N done". Keep the files' original names.

Each round is 4 diagrams for 2 lessons (the 2 most useful per lesson). Round 1 is first because it was already sent from Claude Code.

---
